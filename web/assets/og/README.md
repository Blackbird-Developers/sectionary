Static font cuts for the share card (`src/app/opengraph-image.tsx`). The image
renderer cannot read variable fonts, so these are single-weight files.

- `manrope-800.woff`: Manrope ExtraBold, latin subset, from @fontsource/manrope (SIL OFL 1.1).
- `geist-mono-400.ttf`: Geist Mono Regular (SIL OFL 1.1).
